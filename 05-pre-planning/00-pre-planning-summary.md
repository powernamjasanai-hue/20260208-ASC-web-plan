## 핵심 의사결정 요약

### 1. 대표 타겟 (Primary ICP)

> **세그먼트 A: "만들었는데 안 팔리는 빌더" (60%)**
> - AI로 상품을 만들었지만 판매가 0건
> - 가장 높은 구매력 + 긴급성 + 전환 가능성
> - Hero 카피가 이 사람을 직접 겨냥

### 2. 빅아이디어

> **"AI로 만드는 건 이미 누구나 할 수 있다.
> 진짜 차이는 '파는 구조'를 가진 사람과 가지지 못한 사람 사이에서 벌어진다."**
>
> - 기존 시장: "AI 도구를 잘 쓰면 성공한다"
> - ASC 재정의: "만들기·알리기·팔기·자동화의 전체 구조가 연결되어야 한다"

### 3. 페이지 구조 (HUBED 프레임)

| Phase | 단계 | 섹션 수 | 핵심 목적 |
|-------|------|---------|----------|
| H | Hook (관심) | S1~S4 + BR1 | "내 얘기다" 인식 |
| U | Understand (이해) | S5~S9 + BR2~3 | "체계적이다" 인식 |
| B | Believe (신뢰) | S10~S15 + BR4~5 | "나도 할 수 있다" 확신 |
| E | Envision (시각화) | S16~S19 + BR6~7 | "함께하고 싶다" 욕구 |
| D | Decide (결정) | S20~S24 | "지금 신청해야겠다" 행동 |

**총: 24개 섹션 + 7개 후기 브릿지 = 31개 모듈**

### 4. 기존 초안 대비 주요 추가 섹션

| 새 섹션 | 역할 |

| **S3 시대적 맥락 (Why Now)** | 상단에 긴급성 부여 |

| **S22 투자 대비 ROI** | 가격 정당화 논리 강화 |

### 5. 설득 프레임워크

- **메인**: WHY-HOW-WHAT + PASONA + 사회적 증거
- **상단**: 반상식 + FOMO
- **중단**: 비교 기반 + 앵커링
- **하단**: 손실 회피 + 희소성 + 미루기 방지
