## 1. 서비스 본질 정의

### ASC는 무엇인가?

| 구분 | 기존 포지셔닝 | 리뉴얼 포지셔닝 |
|------|-------------|----------------|
| **정체성** | 강의 판매 플랫폼 | AI 교육 기관/학교 |
| **상품 구조** | 단일 멤버십 | 2-Tier (VOD 119만 + 멤버십 240만) |
| **핵심 가치** | AI 활용법 교육 | 만든 것을 파는 구조까지 완성 |
| **기간** | 기수별 단기 | 연간 멤버십 (1년) |
| **문화** | 강의 수강 | 실행형 커뮤니티 (동료 + 코칭 + 오프라인) |

### ASC의 핵심 차별점 (경쟁 프로그램 대비)

1. **4트랙 선순환 구조**: Creator → Builder → Sales → AI Agent
2. **연간 단위**: 단기 챌린지가 아닌 1년간의 습관 + 구조 형성
3. **파운더 직접 코칭**: 매출 2.7억 달성한 조쉬의 1:1 텍스트 컨설팅
4. **오프라인 인프라**: 안국역/구디역 전용 라운지 + 월 1회 오프라인 모임
5. **노출 기회**: 조쉬의 5만+ 팔로워를 통한 샤라웃/공개 공유회

## 2. 고객 심리 분석

### 외적 문제 (External Problems) — 눈에 보이는 상황

```
ICP A (60%): "AI로 노션 템플릿, SaaS, 콘텐츠를 만들었는데 결제가 0건이다"
ICP B (25%): "SNS 팔로워는 모았는데, 수익화 방법을 모르겠다"
ICP C (15%): "AI로 뭔가 하고 싶은데 뭐부터 해야 할지 모르겠다"
```

**공통 외적 문제:**
- AI 툴은 쓸 줄 아는데, 돈으로 연결이 안 된다
- 혼자서 만들고 혼자서 지친다
- 정보가 너무 많아서 오히려 실행이 안 된다
- 비슷한 온라인 강의를 들어봤지만 결과가 없었다

### 내적 문제 (Internal Problems) — 마음속 고통

```
ICP A: "내가 만든 게 시장에서 가치가 없는 건 아닐까?"
       "시간과 돈을 이미 썼는데, 이게 진짜 되는 건지 확신이 없다"

ICP B: "팔로워가 많은데 왜 돈이 안 되지? 내가 뭘 잘못하고 있나?"
       "상품을 만들어서 팔면 팔로워들이 떠나지 않을까?"

ICP C: "나만 뒤처지고 있는 것 같다"
       "시작도 안 했는데 벌써 늦은 건 아닐까?"
```

**공통 내적 문제:**
- **자기 의심**: 내가 이걸 할 자격이 있나
- **고립감**: 혼자서 모든 걸 해야 한다는 부담
- **비교 심리**: 다른 사람들은 잘 되는 것 같은데 나만 안 되는 느낌
- **완벽주의 마비**: 완벽하게 준비되지 않으면 시작하지 못하는 패턴

### 욕구 (Desires) — 진짜 원하는 것

```
1차 욕구 (표면): AI로 수익 내기, 1인 창업 시작하기
2차 욕구 (깊은): 회사에 의존하지 않는 독립적인 삶
3차 욕구 (본질): 내가 원하는 방식으로 사는 자유 + 자기 효능감
```

**구체적 욕구 리스트:**
- 만든 것으로 실제 매출이 발생하는 경험
- "나도 할 수 있다"는 확신
- 같은 방향의 동료 + 멘토와의 연결
- 체계적인 로드맵 (뭘 해야 하는지 명확함)
- 더 적은 시간으로, 더 많은 소득 (조쉬의 라이프스타일)

### 두려움 (Fears) — 행동을 막는 것

```
구매 전 두려움:
- 240만원이 아까운 돈이 되면 어쩌지?
- 또 강의만 듣고 끝나면 어쩌지?
- 나만 수준이 낮으면 어쩌지?
- 직장/육아 병행하면서 할 수 있을까?

구매하지 않을 때의 두려움 (FOMO):
- AI 시대에 혼자 뒤처지는 것
- "5시간 만에 마감"인데 나만 놓치는 것
- 가격이 계속 올라서 나중에 더 비싸지는 것
- 이 기회를 놓치면 독립의 타이밍을 놓치는 것
```

### 결핍 (Deficiencies) — 현재 부족한 것

| 결핍 영역 | 구체적 결핍 | ASC의 해결 |
|----------|-----------|-----------|
| **판매 구조** | 만들기만 하고 팔 줄 모름 | Sales 트랙 + 퍼널/랜딩 강의 |
| **피드백 루프** | 혼자서 뭐가 잘못됐는지 모름 | 주 1회 그룹 컨설팅 + 1:1 텍스트 |
| **실행 환경** | 혼자 하면 동기 부여 저하 | 4주 코호트 + 조별 인증 |
| **기술적 역량** | 바이브코딩, AI 자동화 모름 | Builder/AI Agent 트랙 |
| **네트워크** | 같은 방향의 동료가 없음 | 50명+ 커뮤니티 + 오프라인 |
| **방향성** | 뭘 해야 하는지 모름 | 매달 트랙 선택 + 커리큘럼 |

### 가장 원하는 상황 (해피 엔딩)

> "1년 뒤, AI를 활용한 나만의 서비스로 월 수백만 원의 수익이 발생하고,
> 50명 이상의 강력한 동료 네트워크가 있고,
> 회사에 의존하지 않아도 되는 독립적인 삶의 기반이 만들어져 있다.
> 아침에 눈을 뜨면 '오늘은 뭘 만들어볼까' 설레는 마음으로 하루를 시작한다."

### 가장 피하고 싶은 상황 (배드 엔딩)

> "1년 뒤, 여전히 같은 자리에서 같은 고민을 반복하고 있다.
> AI를 쓰는 사람들과의 격차는 더 벌어졌고,
> '그때 시작했더라면...'이라는 후회만 남아 있다.
> 혼자서 시도했지만 결국 흐지부지 포기하고,
> 240만원이 아니라 '1년이라는 시간'을 잃었다는 사실이 더 아프다."

## 3. 전환 실패 원인 분석 (CRM 데이터 기반)

클라이언트 미팅에서 확인된 현재 전환 병목:

| 퍼널 단계 | 데이터 | 분석 |
|----------|--------|------|
| 이메일 시퀀스 오픈 | 양호 | 관심은 있음 |
| 랜딩페이지 접속 | 12~13명 | 클릭은 했음 |
| 결제창 진입 | 소수 | 관심 → 고려 전환됨 |
| 최종 결제 | 0건 | **가격 이탈 또는 너처링 부족** |

**핵심 병목: "관심은 있지만 확신이 없다"**

→ 랜딩페이지가 해결해야 할 가장 중요한 과제:
1. **가격 정당화**: 240만원이 투자할 만한 가치라는 확신
2. **셀프 너처링**: 페이지를 읽는 것만으로 "이건 나를 위한 것"이라는 감정 형성
3. **리스크 해소**: "실패해도 괜찮다" + "30일 환불 보장"
4. **긴급성**: "지금 안 하면 더 비싸진다" + "소수 인원 제한"
