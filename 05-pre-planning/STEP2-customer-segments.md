# STEP 2: 고객 세그먼트 정의

> 구매력과 전환 가능성이 높은 3개 세그먼트를 정의하고,
> 랜딩페이지의 대표 타겟 세그먼트를 선정합니다.

---

## 세그먼트 A: "만들었는데 안 팔리는 빌더" (60%)

### 페르소나

| 항목 | 내용 |
|------|------|
| **대표 이름** | 김건우 (32세, 남성) |
| **현재 상태** | IT 대기업 기획자 / 퇴사 고민 중 |
| **AI 활용 수준** | 중급 — ChatGPT, Notion AI 적극 사용 |
| **만든 것** | 노션 템플릿 3개, 간단한 SaaS 프로토타입 1개 |
| **수익** | 0원 (한 번도 팔아본 적 없음) |
| **SNS** | 스레드 팔로워 200명대, 간헐적 포스팅 |
| **가용 예산** | 200~300만원 (자기 투자에 과감함) |
| **시간** | 평일 저녁 + 주말 (주 10~15시간) |

### 심리 상태

```
외적 상황: "노션 템플릿도 만들고, SaaS도 만들었는데 결제가 0건이에요"
내적 독백: "뭐가 문제인지 모르겠어. 상품이 안 좋은 건가, 마케팅을 못하는 건가?"
감정 상태: 좌절 + 조급함 + "이미 시간을 투자했으니 포기 못 함"
```

### 이 사람이 ASC에서 얻고 싶은 것

1. **"왜 안 팔리는지"에 대한 진단** → 그룹 컨설팅 + 조쉬 피드백
2. **판매 구조/퍼널 설계** → Sales 트랙
3. **같은 상황의 동료** → "나만 안 되는 게 아니구나" 안도감

### 전환 트리거

- "오픈 2분 매진 + 대기자 100명" 같은 **구체적 성과 후기**
- "1회 판매에 1.8억" 같은 **파운더의 실전 경험**
- "만든 것을 파는 구조까지" 라는 **정확한 약속**

### 전환 저항

- 가격 (240만원): "또 돈 쓰고 안 되면 어쩌지?"
- 시간: "직장 다니면서 정말 할 수 있을까?"
- 과거 실패: "비슷한 강의 들었는데 소용없었음"

## 세그먼트 B: "팔로워는 있는데 수익이 없는 크리에이터" (25%)

### 페르소나

| 항목 | 내용 |
|------|------|
| **대표 이름** | 이수진 (29세, 여성) |
| **현재 상태** | 프리랜서 마케터 / 1인 크리에이터 병행 |
| **AI 활용 수준** | 초~중급 — AI로 콘텐츠 제작 |
| **만든 것** | 콘텐츠 (블로그, 뉴스레터, SNS) |
| **수익** | 콘텐츠 자체 수익 거의 없음 |
| **SNS** | 스레드/인스타 팔로워 1,000~3,000명 |
| **가용 예산** | 100~200만원 (VOD로 시작할 가능성 높음) |
| **시간** | 비교적 유연 (주 15~20시간) |

### 심리 상태

```
외적 상황: "팔로워는 늘었는데, 이걸로 뭘 해야 하는지 모르겠어요"
내적 독백: "콘텐츠는 자신 있는데, 상품을 만들어서 파는 건 다른 영역이야"
감정 상태: 가능성은 느끼지만 + 다음 스텝이 막막함
```

### 이 사람이 ASC에서 얻고 싶은 것

1. **오디언스 → 수익 전환 방법** → Creator + Sales 트랙 연계
2. **디지털 상품 기획/제작** → Builder 트랙
3. **퍼스널 브랜딩 고도화** → 조쉬의 샤라웃 + 공유회

### 전환 트리거

- "4주 만에 팔로워 2배 성장" 같은 **크리에이터 트랙 성과**
- "오디언스를 구축하는 방법을 배울 수 있었다" 후기
- VOD로 먼저 시작 → 멤버십 업그레이드 경로

### 전환 저항

- 가격: VOD(119만)는 가능, 멤버십(240만)은 부담
- "내가 상품을 만들 수 있을까?" 자기 의심
- 커뮤니티 문화에 대한 불안 ("부담스럽지 않을까?")

## 세그먼트 C: "AI 시대에 뭔가 해야 하는데 못 시작한 예비 창업가" (15%)

### 페르소나

| 항목 | 내용 |
|------|------|
| **대표 이름** | 박민준 (36세, 남성) |
| **현재 상태** | 대기업 팀장 / 퇴사 후 1인 창업 준비 |
| **AI 활용 수준** | 초급 — ChatGPT 기본 사용 정도 |
| **만든 것** | 아직 없음 |
| **수익** | 0원 (사이드 프로젝트 무경험) |
| **SNS** | 없거나 개인 계정 수준 |
| **가용 예산** | 200~500만원 (퇴직금/저축 활용) |
| **시간** | 퇴사 준비 중이라 투자 의지 강함 |

### 심리 상태

```
외적 상황: "AI로 뭔가 하고 싶은데, 뭐부터 시작해야 할지 막막해요"
내적 독백: "회사 다니면서 이대로 늙고 싶지 않은데..."
감정 상태: 막연한 불안 + 강한 열망 + 방향성 부재
```

### 이 사람이 ASC에서 얻고 싶은 것

1. **처음부터 끝까지의 로드맵** → 4트랙 순서대로 따라가기
2. **시작의 용기** → 커뮤니티 동료 + "나도 할 수 있다" 경험
3. **구글/삼성 출신 동료들** → "이런 사람들도 하는구나" 안도감

### 전환 트리거

- "직장/육아 병행하면서도 성과를 냈다" 후기
- 구글/삼성/스타트업 대표 등 **Peer Group의 수준**
- "연간 프로그램"이라는 **충분한 시간적 안정감**

### 전환 저항

- "내가 따라갈 수 있을까?" 수준 불안
- "아직 시작도 안 했는데 240만원?" 시기상조 느낌
- 구체적인 결과가 예측되지 않는 불확실성

## 대표 타겟 세그먼트 선정

### 1순위 타겟: **세그먼트 A "만들었는데 안 팔리는 빌더"**

**선정 이유:**

| 기준 | 세그먼트 A | 세그먼트 B | 세그먼트 C |
|------|----------|----------|----------|
| **구매력** | ★★★★★ | ★★★☆☆ | ★★★★☆ |
| **긴급성** | ★★★★★ | ★★★☆☆ | ★★☆☆☆ |
| **전환 가능성** | ★★★★★ | ★★★☆☆ | ★★☆☆☆ |
| **ASC 적합도** | ★★★★★ | ★★★★☆ | ★★★☆☆ |
| **비율** | 60% | 25% | 15% |

**핵심 근거:**
- 이미 "만들기"를 시도해봤으므로 **실행력은 있음**
- "안 팔림"이라는 **구체적 문제**가 있어 솔루션 전달이 명확
- 시간/돈을 이미 투자했으므로 **매몰 비용 효과**로 전환 의지 높음
- ASC의 핵심 가치("만든 것을 파는 구조")와 **완벽히 일치**

### 랜딩페이지 설계 원칙

```
메인 히어로: 세그먼트 A를 직접 겨냥 (60%)
서브 진입점: 세그먼트 B/C도 "내 얘기다"라고 느낄 수 있는 문제 정의 섹션
상품 분기: VOD(B/C 진입) vs 멤버십(A 직접 전환)
```
